# 제조본부장 주간보고 (2026-11-16) — 입력 예시

1. Gate 2차 재평가 계획 및 catch-up plan 수립 현황
1) 미충족 항목 확인을 위한 1차 재평가 결과 요약
① Gate #1 미달 4건(상업화 Risk 2건, JC 파일럿 2건) 대상 1차 재평가 (11/5) 결과 미완료 항목 3건에 대한 2차 재평가 계획 수립
② 미달 항목은 2차 재평가에서 검증 완료 예정 (12/4)
[표. 1] Gate #1 미달 항목별 재평가 결과 및 2차 재평가 일정
| 구분 | 점검 항목(목표) | 1차 재평가(11/5) | 미달 사유 | 2차 재평가 |
|---|---|---|---|---|
| 상업화 Risk#1 | Module High-Risk: CTM 재현성 | 미달 | 샘플 모수 부족 | 12/4 예정 |
| 상업화 Risk#2 | Module High-Risk: 모듈 설비 배치 사양 | 미달 | 라벨 출력 측정 방안(offset 기법) 결과 신뢰성 낮음 | 12/4 예정 |
| JC 파일럿 | cell 효율(≥ 28.0%) | 통과(28.6%) | - | - |
| ^^ | FpG(셀 양품률, ≥ 95.0%) | 미달(50%, 11/13 재측정 80%) | 공증착 Nozzle 막힘으로 인한 FpG 목표 대비 미달 | 12/4 예정 |
2) 미달 항목 해소를 위한 2차 재평가 계획
① 미달 3건 모두 12/4 2차 재평가로 Gate #1 전 항목 통과 목표
② 파일럿 FpG catch-up plan 수립 완료
a) Wet station 공정으로 인한 후면 패드 정상 반영하였으나 최종 FpG 80%로 목표 (95%) 미달
b) 공증착 공정 시 nozzle 막힘현상 반복 발생으로 FpG저하 발생. 2차 재평가까지 해소 계획 수립
③ 상업화 Risk 2건은 계획 수정 중으로 11/16 완료 예정
a) CTM 재현성: 신규 cell sorting criteria 기반 대량 모듈 결과 확보, JC BKM 반영 여부 검증
b) 모듈 설비 배치 사양: 기술본부 모듈 라벨 측정 계획(offset 측정) 결론, 모듈 라벨 출력 방안 검증

2. 선익시스템 양산 증착기 개발 현황
1) 신규 양산 설비 개발 현황
① 고가 재료인 C60을 대상으로 Material Recycle System 개발
a) 증착 중 외벽에 버려지는 재료를 basket에 회수해 재사용
b) Basket과 linear source 구조를 동일하게 설계해 별도 조치 없이 회수 재료 재투입 가능
2) 양산 적용 시 유효성
① 버려지던 C60을 회수해 재료 사용 효율을 높이는 구조로, 양산 적용 시 재료비 절감 가능
② 단, 재사용 재료의 공정 재현성과 효율 수치는 업체 제시 기준으로 당사 검증 전 단계
[표. 2] Material Recycle System 검증 항목 및 업체 제시 효과
| 구분 | 검증 항목 | 업체 제시 현황 |
|---|---|---|
| 공정 재현성 | 증착 Rate 재현 | 검증 진행 [확인필요: 결과] |
| 물질 특성 재현성 | C60 물질 특성(Powder XRD, TOF-SIMS 분석) | 검증 진행 [확인필요: 결과] |
| 재료 사용 효율 | 재료 사용 유효율 | 일반 증착기 40% → 선익 신규 공정 60% |
3) 후속 검토 사항
① 재료 사용 유효율 산정 근거 및 타사 비교 데이터 확보 (선익 추가 검토 예정)
② 재사용 재료 재현성 검증 결과 확인 후 당사 양산 적용 여부 검토
