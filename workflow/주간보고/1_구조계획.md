# 1단계 · 제조본부장 주간보고 구조 계획

## 메타
| 항목 | 내용 |
|------|------|
| 제목 | 제조본부장 주간보고 |
| 독자 | 제조본부장, 대표이사 |
| 형태 | Word(.docx) 1건 (`scripts/build_report.py`) |
| 분량 | 주제당 1p 내외 |
| 넘버링 | `1.` → `1)` → `①` → `a)` → `i)` |
| 원자료 | 항목별로 채팅 붙여넣기 |

## 목차

```
핵심 요약 (주제별 1줄 결론)

1. Gate 2차 재평가 계획 및 catch-up plan 수립 현황
   1) 미충족 항목 확인을 위한 1차 재평가 결과 요약      [표1]
   2) 판정 기준 확정을 위한 2차 재평가 계획             [표2]

2. 선익시스템 양산 증착기 개발 현황
   1) 신규 양산 설비 개발 현황
   2) 양산 적용 시 유효성
   3) 후속 검토 사항

3. 양산 Wet station 공정 비교 - SC China vs. 당사
   1) 공정 비교 검토 사유
   2) 주요 공정 차이 및 의미                          [표3]
   3) 향후 계획
```

## 절별 성격과 결정 사항

| 절 | 성격 | 결정 사항 |
|----|------|-----------|
| 1. | Gate 1 재평가의 2차 계획 (11/5 1차 재평가 후속) | catch-up 소절은 두지 않고 2)의 표2에 흡수, 주제명 유지 |
| 2. | 선익시스템이 영업 목적으로 제안한 미팅 내용 중 의미 있는 개발 내용 요약 | 업체 제안 정리 수준으로 분량 절제, 소제목은 목적 문구 없이 지정 문구 사용 |
| 3. | SC China와 당사 Wet station 공정 비교 | 소제목은 목적 문구 없이 지정 문구 사용 |

## 표 목록
- **표1** Gate 1 1차 재평가 결과: 영역별 KPI, 1차 결과, 갭
- **표2** 2차 재평가 계획 및 catch-up: 대상 항목, 판정 기준, 보완 조치, 완료일, 2차 판정 `[MM/DD 결과: 충족 / 미충족]`
- **표3** Wet station 공정 비교: 공정 단계별 SC China, 당사, 차이의 의미
- 2번 절 표는 미팅 자료 확인 후 결정

## 진행 순서
1번 자료 수령 → 1번 개요 작성 → 검토 → 2번 → 3번 → docx 빌드
